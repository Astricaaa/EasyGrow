# Declaración de Propiedad Intelectual y Licencias

Este proyecto implementa una arquitectura y experiencia visual 100% original para la plataforma **EasyGrow**, cumpliendo con los estándares de diseño y desarrollo ético:

1. **Código y Lógica**: Todo el código JavaScript, CSS y HTML fue desarrollado de manera original para este proyecto. No se utiliza código privativo de terceros ni fragmentos copiados.
2. **Iconografía y Gráficos**: Los iconos, elementos visuales e ilustraciones se generan de forma procedural mediante SVG vectorial estándar y canvas nativo.
3. **Representación de Moneda**: Las partículas utilizadas en la barra de carga son representaciones geométricas estilizadas con el glifo estándar universal `$`. No corresponden ni reproducen billetes, retratos, números de serie ni elementos de divisas oficiales reales.
4. **Modelo 3D del Portátil**: Geometría paramétrica procedural generada en tiempo de ejecución utilizando primitivas matemáticas estándar (cajas y biseles). No representa modelos registrados, marcas comerciales ni equipos específicos del mercado.
5. **Bibliotecas de Terceros de Código Abierto**:
   - **Three.js** (r128) - Licencia MIT: Motor de renderizado WebGL 3D utilizado para proyectar la malla paramétrica y calcular la iluminación especular en tiempo real.
